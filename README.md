# Zod

Zod is a TypeScript-first schema validation library. Define a schema once, validate values at runtime, and infer the corresponding TypeScript types from that schema.

## Why Zod?

Use schemas to describe the expected shape of data at application boundaries, including:

- API requests
- Configuration loading
- Form submissions

Validation produces either parsed, typed data or structured errors that can be used to report invalid input.

## Project tasks

The `Makefile` provides common Node.js project tasks and assumes that matching npm scripts are configured in `package.json`.
